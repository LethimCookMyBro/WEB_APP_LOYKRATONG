# 🪷 Interactive Paper-to-3D Loy Krathong & Thai-Japanese Language Exchange

ระบบเว็บลอยกระทง 3 มิติ ผสานการแลกเปลี่ยนภาษาและวัฒนธรรมไทย–ญี่ปุ่น
ผู้เข้าร่วมฝึกเขียนชื่อและคำอวยพรเป็นภาษาของเพื่อน → เขียนลงกระดาษ A4 แบบเดียวกันทุกคน → พับเป็นกระทง → ถ่ายภาพด้วยมือถือ → ปัดขึ้นเพื่อลอยกระทงไปยังจอโปรเจกเตอร์

| หน้า | URL | ใช้ทำอะไร |
| :--- | :--- | :--- |
| ผู้เข้าร่วม (มือถือ) | `/` | เลือกภาษา → ชื่อ → คำอธิษฐาน → เขียน & พับ → ถ่ายภาพ → ลอยกระทง |
| ผู้ดำเนินรายการ | `/host` | ใส่ PIN, ปัดเปิดพิธี, สอนคำอวยพรบนจอใหญ่, ตั้งค่า QR/เสียง, นำกระทงที่ไม่เหมาะสมออก |
| จอโปรเจกเตอร์ | `/stage` | แม่น้ำยามค่ำคืน, พิธีเปิด, กระทงของทุกคนลอยแบบ Real-time |
| กระดาษ A4 | `/template.html` | พิมพ์กระดาษ (มี QR สำหรับเข้าร่วม) หรือใช้ไฟล์ `public/assets/templates/a4-origami-sheet.pdf` |

## 🚀 เริ่มใช้งาน

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
```

```bash
HOST_PIN=2569 npm start
```

หน้าต่าง Terminal จะแสดง URL ทั้งหมดและรหัส **HOST PIN** (ถ้าไม่ตั้ง `HOST_PIN` ระบบจะสุ่มให้ทุกครั้งที่เปิดเซิร์ฟเวอร์)

### เปิดให้มือถือเข้าผ่านอินเทอร์เน็ต (Cloudflare Tunnel)
กล้องบนมือถือใช้ได้เฉพาะเว็บที่เป็น **HTTPS** (หรือ `localhost`) จึงควรเปิดผ่าน Cloudflare Tunnel:

```bash
cloudflared tunnel --url http://localhost:3000
```

จากนั้นนำลิงก์ `https://xxxx.trycloudflare.com/` ไปใส่ในหน้า `/host` → ช่อง “ลิงก์สำหรับผู้เข้าร่วม” แล้วกด **บันทึก**
(หรือเปิดหน้า `/host` ผ่านลิงก์ tunnel แล้วกด “ใช้ลิงก์ของหน้านี้”) — QR บนจอใหญ่และบนกระดาษ `/template.html` จะเปลี่ยนตามทันที
หรือตั้งตั้งแต่เริ่มด้วย `PUBLIC_URL=https://xxxx.trycloudflare.com/ npm start`

> ถ้าใช้ผ่าน Wi-Fi วงเดียวกันแบบ `http://192.168.x.x:3000` กล้องสดจะเปิดไม่ได้ แต่ผู้เข้าร่วมยังกด “เลือกรูปจากเครื่อง” (ถ่ายด้วยแอปกล้องปกติ) หรือ “วาดบนจอแทน” ได้

### ลำดับในวันงาน
1. เปิด `/stage` บนเครื่องที่ต่อโปรเจกเตอร์ แล้ว **คลิกหนึ่งครั้ง** (เพื่อเปิดเสียงและเต็มจอ) — ฉากจะมืดสลัวและรอพิธีเปิด
2. ผู้ดำเนินรายการเปิด `/host` ใส่ PIN → ใช้ “สอนคำอวยพรบนจอใหญ่” อธิบายคำและการออกเสียง
3. ผู้เข้าร่วมสแกน QR → ทำตามขั้นตอนบนมือถือ → หน้าลอยกระทงจะ **ล็อก** ไว้
4. ผู้ดำเนินรายการ **ปัดขึ้น** บนจอ “กระทงปฐมฤกษ์” → จอใหญ่เกิดคลื่นแสงสีทอง โคมลอยสว่าง เพลงเทศกาลเริ่ม และมือถือทุกเครื่องปลดล็อกหลังจากนั้นราว 6.5 วินาที
5. ผู้เข้าร่วมปัดขึ้น → กระทงลอยพ้นขอบบนของมือถือ → ไปปรากฏที่ท่าน้ำบนจอใหญ่พร้อมวงคลื่น

**ปุ่มลัดบนจอใหญ่:** `F` เต็มจอ · `M` ปิด/เปิดเสียง · `Q` QR ใหญ่/เล็ก · `H` ซ่อนข้อความ · `D` โหมดทดสอบ (ส่งกระทงตัวอย่างอัตโนมัติ ใช้ซ้อมได้โดยไม่ต้องมีมือถือ) — หรือเปิด `/stage?demo=1`

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |

## 🔌 Socket.io events

| ทิศทาง | Event | ข้อมูล |
| :--- | :--- | :--- |
| มือถือ → server | `spawn_krathong` | รูปแบบตามสเปก (ด้านล่าง) + `displayName` ตอบกลับ `{ ok, id }` หรือ `{ ok:false, error }` |
| server → จอใหญ่ | `spawn_krathong` | ข้อมูลกระทงที่ตรวจแล้ว + `receivedAt` |
| host → server | `host_auth` `{pin}` · `start_ceremony` `{krathong}` · `reset_ceremony` · `clear_river` · `remove_krathong` `{id}` · `show_lesson` `{wishId}` · `set_join_url` `{url}` · `stage_control` `{action, value}` | ทุก event ของ host ต้องผ่าน PIN ก่อน |
| server → ทุกคน | `ceremony_state` `{opened, opening}` | มือถือใช้ล็อก/ปลดล็อกปุ่มส่ง |
| server → จอใหญ่ | `ceremony_open` · `river_snapshot` · `lesson` · `join_url` · `stage_control` · `remove_krathong` · `river_clear` · `river_reset` | |

```json
{
  "id": "user_1730184000",
  "isHost": false,
  "languageMode": "JP_TO_TH",
  "selectedWishId": "research_fast",
  "colors": { "base": "#2E7D32", "innerPetal": "#FF8F00", "outerPetal": "#D84315", "flower": "#FDD835" },
  "handwritingImageBase64": "data:image/png;base64,...",
  "displayName": "ทานากะ"
}
```

เซิร์ฟเวอร์จะ: บังคับ `isHost=false` สำหรับผู้เข้าร่วม, รับเฉพาะรูป `data:image/png|webp|jpeg` ไม่เกิน ~1 MB, สีต้องเป็น `#RRGGBB`, ตัดข้อความชื่อไม่เกิน 40 ตัวอักษร และจำกัดการส่งถี่เกินไป (ต่อเครื่องและต่อ IP)

## 🧠 วิธีการทำงานของแต่ละส่วน (และข้อจำกัดที่ควรรู้)

**กระดาษ A4 (Universal Template)** — พื้นกระทง 90×90 มม. ผนัง 4 ด้านเป็นรูปคางหมู (ฐาน 90 ด้านบน 114 สูง 24 มม.) เมื่อพับขึ้นและทากาวที่แถบมุม ผนังจะบานออกประมาณ 30° พื้นกลางที่มีกรอบคำอธิษฐาน 72×50 มม. จึงยังหงายขึ้นและแบนราบ กรอบมีจุดดำ 6×6 มม. ที่มุมทั้ง 4 (ศูนย์กลางห่างกัน 80×58 มม.)
⚠️ ระยะต่าง ๆ คำนวณจากเรขาคณิตแล้ว แต่ **ยังไม่ได้ทดลองพับกับกระดาษจริง** ควรพิมพ์และพับต้นแบบ 2–3 ชิ้นก่อนวันงาน ถ้าปรับขนาดใน `template-svg.js` ต้องปรับค่าใน `image-processor.js` (`TEMPLATE`, `ZONES`) ให้ตรงกันด้วย และต้องพิมพ์ขนาดจริง 100%

**การถ่ายภาพ** — กล้องมีกรอบเล็งและตรวจหาจุดดำ 4 มุมสด ๆ (มุมเป็นสีเขียวเมื่อเจอ) เมื่อถ่ายแล้วจะเข้าหน้า “ปรับมุม” ให้ผู้ใช้ลากแก้ได้เสมอ จากนั้น:
- **Handwriting extraction:** แก้มุมมองด้วย homography → ตัดเฉพาะกรอบ → Adaptive Threshold (Bradley–Roth ด้วย integral image) → PNG พื้นหลังโปร่งใส
- **Color sampling:** อ่านสีจากหลายจุดในแต่ละโซน (ฐาน, กลีบใน, กลีบนอก, ดอกไม้) เลือกจุดที่มีสีชัดที่สุด ถ้าเป็นกระดาษขาว/อ่านไม่ได้จะใช้สีเริ่มต้นและบอกผู้ใช้ ผู้ใช้แตะแก้สีได้
- ตำแหน่งผนังและกลีบหลังพับอยู่สูงกว่าพื้น จึงเป็นการ **ประมาณ** — ผลขึ้นกับมุมกล้องและแสง
- ทดสอบแล้วกับภาพจำลอง (กระดาษเรียบที่เอียงมุม) แต่ **ยังไม่ได้ทดสอบกับกระทงที่พับจริงและกล้องมือถือหลายรุ่น**

**การแปลงชื่อ**
- ญี่ปุ่น → ไทย: รับโรมาจิหรือคานะ ใช้หลักการถอดเสียงแบบราชบัณฑิตยสถาน (เช่น k ต้นคำ = ค, กลางคำ = ก) + พจนานุกรมชื่อที่นิยม (เช่น Tanaka → ทานากะ, Sato → ซาโต้) ชื่อที่เป็นคันจิแปลงไม่ได้ (ระบบจะขอให้พิมพ์เป็นโรมาจิ/คานะ)
- ไทย → คาตาคานะ: รับอักษรไทยหรือการสะกดอังกฤษ ใช้กฎแยกพยางค์โดยประมาณ + พจนานุกรมชื่อเล่นที่นิยม
- ภาษาไทยมีสระแฝง/ตัวการันต์/คำควบกล้ำที่กำกวม กฎจึงผิดได้ในบางชื่อ (เช่น “ธนวัฒน์”) — หน้าจอจึงบอกว่า “โดยประมาณ” และให้ **แก้ไขเองได้** ทุกครั้ง แนะนำให้มีอาสาสมัครเจ้าของภาษาช่วยตรวจในงาน

**แบบฝึกเขียน (Pattern View)**
- ภาษาญี่ปุ่น (คาตาคานะ ฮิรางานะ และคันจิในคำอวยพร): **ลำดับขีดจริง** จาก [KanjiVG](https://kanjivg.tagaini.net) แสดงเป็นแอนิเมชันพร้อมเลขลำดับขีด
- ภาษาไทย: ยังไม่มีชุดข้อมูลลำดับขีดภาษาไทยแบบเปิด จึงแสดงเป็น **ตัวอักษรเส้นประแบบมีหัว (Noto Sans Thai Looped) บนเส้นบรรทัด 4 เส้น** พร้อมแอนิเมชันทีละตัว และคำแนะนำทั่วไป (เริ่มจากหัวกลม เขียนพยัญชนะก่อน แล้วค่อยสระ/วรรณยุกต์) — ไม่ได้อ้างว่าเป็นลำดับขีดที่ถูกต้องทุกตัว

**ฉาก 3 มิติ** — Three.js: กระทง procedural (ฐานหยวกกล้วย กลีบพับ 3 ชั้น ดาวเรือง เทียน ธูป ควัน) แบ่ง Material เป็น base/innerPetal/outerPetal/flower, ป้ายลายมือเป็น `THREE.Sprite` (หันหาจอเสมอ) เรืองแสง, น้ำเป็น shader สะท้อนพระจันทร์และแสงเทียน, `RingGeometry` วงคลื่น, `CatmullRomCurve3` เส้นทางแม่น้ำ, โยกขึ้นลงด้วย `sin`/`cos`, กันชนกันด้วยการผลักระยะห่าง, `EffectComposer` + `UnrealBloomPass`
- ใช้ PointLight จำนวนคงที่ 6 ดวงหมุนเวียนให้กระทงที่ใกล้กล้องที่สุด (ถ้าเพิ่ม/ลดจำนวนแสงตลอดเวลา เบราว์เซอร์ต้องคอมไพล์ shader ใหม่และจะกระตุก)
- จอใหญ่จะลดความละเอียดอัตโนมัติถ้า FPS ต่ำ และแสดงกระทงพร้อมกันได้สูงสุด 55 ลำ (`/stage?max=40` เพื่อลด)
- **ใช้โมเดลของตัวเอง:** วาง `public/assets/models/krathong.glb` ระบบจะโหลดแทน โดยตั้งชื่อ material ให้มีคำว่า `base`, `inner`, `outer`, `flower`

**เสียง** — ไม่มีไฟล์ mp3 มาให้ ระบบจึงสร้างเพลงบรรเลงแบบ generative (ระนาดบันไดเสียงเพนทาโทนิก ฉิ่ง-ฉาบ ฆ้อง เสียงน้ำ) เป็นเพลงที่แต่งขึ้นใหม่ ไม่ใช่ทำนองเพลงลอยกระทงต้นฉบับ (ซึ่งมีลิขสิทธิ์)
ถ้าต้องการใช้เพลงจริง วาง `public/assets/audio/bgm-loykrathong.mp3` และ/หรือ `splash-chime.mp3` (ต้องมีสิทธิ์ใช้งานเพลงนั้น)
